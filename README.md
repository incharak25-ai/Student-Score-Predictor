# Student Score Predictor

## Project Description

This project predicts a student's exam score based on the number of hours studied using Machine Learning.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm

Linear Regression

## Features

- Creates a sample dataset
- Visualizes data
- Trains a Linear Regression model
- Predicts student scores
